组会汇报 · 2026-09-25

接触动力学建模：文献、结果与方向

三个部分：① 已有方法都由同样的六个部件组成，差别在于每个部件是写死的物理还是学出来的，按这个骨架能看清谁做了什么、哪里没人做；② 我们在真实力控插入数据上的实验：混合模型（刚体仿真 + 按接触点修正）把 100 步推演位置误差从 4.80 mm 降到 3.55 mm，单核 CPU 每步 3 ms，纯学习的 Act-FIGNet 为 2.87 mm 但要 GPU；③ 从误差来源和项目目标推导出的修改方向，而不是继续试错。

我们的数字都来自同一套评测（100 步开环推演，按轴 RMSE：位置 mm / 姿态 °）。论文数字取自 arXiv:2509.12151 v3 Table III。文献部分基于摘要和可访问全文，不确定处已标注。

PART 1

文献综述：共性骨架与各家的取舍

1.1 所有方法共享的六个部件

一个接触动力学模型 = 几何怎么表示 + 怎么找接触 + 哪些定律写死 + 网络管什么 + 力和运动怎么耦合 + 用什么信号训练。两个旋钮决定一种方法的位置：③ 物理先验写死多少，④ 学习单元切多细。

部件要回答的问题可选项（从物理到学习）
① 几何表示物体用什么描述解析参数 → 凸网格 → SDF / 点云 → 学出来的 SDF
② 接触结构谁和谁在接触、在哪、法向求解器接触点 → 面-面碰撞边 → 隐式（不显式表示）
③ 物理先验哪些定律写死全部（仿真器） → 非穿透 + 摩擦锥 + 力臂 → 只保留旋转等变 → 无
④ 学习单元网络管什么几个参数 → 全局修正 → 每个接触点 → 每个顶点 → 每个粒子
⑤ 力-运动耦合力和运动是同一个量的两面吗天然耦合（仿真） → 力臂合成 → 分别回归
⑥ 训练信号用什么数据、怎么训参数拟合 → 单步位姿 / F/T → 多步 / 在线数据 → 仿真预训练 + 真实微调

1.3 定位图

1.4 已经证明走不通、或代价不值得的路

走不通 全局残差

④ 选整体：Ajay 2018 在 2D 任务上可以，Act-FIGNet 的 baseline 和我们的复现在插入任务上都发散。它可以在任何地方凭空加力，和约束打架。

走不通 隐式编码接触

② 不显式表示接触在哪（Tracy 2023）：控制够用，换几何失效。几何条件必须显式。

走不通 纯隐空间世界模型

③ 全部丢掉：分布外差、不可解释，与"泛化、可解释"目标冲突。

走不通 学自由空间动力学

我们的诊断：自由空间残差是噪声（见 2.4），多帧历史也解释不了。⑥ 里没有信号可学。

代价不值 推理时替换仿真器

F 类：预训练省数据，但失去不穿透等保证，等于回到纯学习。

代价不值 精细几何标定

我们的实验：可解释范围内的修正只带来 2–3%；再调就过拟合。而且与"更少标定"目标相悖。

1.5 各家做了什么、还缺什么（按部件）

部件做得最好的没人做的 / 做得不够的
① 几何FIGNet 系列：整张网格进图；ContactNets：学未知物体的 SDF装配任务里"局部几何决定泛化"的直接证据（只有我们的 3 种工具，证据不足）
② 接触结构FIGNet：面-面碰撞边，不依赖求解器一步之内接触事件（开始/结束）的处理：所有方法都假设一步内不变
③ 物理先验Posa 组：定律作损失；Jiang：约束保留在真实力控装配数据上，"保留仿真器 + 约束 + 局部学习"的组合（我们填的空）
④ 学习单元Act-FIGNet：每顶点；QuasiSim：每接触对每接触对 + 真实 F/T（我们）；输出"接触参数"而非力的变体（无人做）
⑤ 耦合Act-FIGNet 与我们：力臂合成—（这一点已经是共识）
⑥ 训练信号Act-FIGNet：F/T + 噪声注入；我们：线性化 + DAgger多步/在线数据与真实 F/T 的结合；多套硬件（所有方法都绑定一台机器人一个控制器）
PART 2

我们的实验与分析

2.1 设置

数据与协议

Act-FIGNet 公开数据：UR10e + 六维力传感器，笛卡尔力控，10 Hz。圆柱、六边形训练（40 万步），方形只在测试集；另有专家插入、绕圈两种分布外策略。评测沿用论文：100 步推演位姿误差、单步 F/T；另加推演中 F/T 与每步耗时。

基础仿真

数据自带的简化 MuJoCo 场景 + 辨识的导纳动力学（逐轴虚拟质量 400–900 kg、阻尼 900–1300 N·s/m）+ 接触参数搜索 + 两项几何修正（圆柱网格膨胀、插座高度各 0.45 mm）。

LCR

MuJoCo 留 3 mm 余量找接触点；每个点在自己的坐标系里取 67 维特征（含局部 SDF 块）；共享 MLP + 1 层注意力；输出受约束的修正力（法向只推不拉、摩擦锥）；力臂合成，同一修正进运动和 F/T。约 4 万参数。

训练

预计算每个样本的一步线性化表，训练只做矩阵乘法（CPU 5–10 分钟，不需要可微仿真）；再用 DAgger 在模型自己走到的状态上重新线性化并微调。

2.5 和 Act-FIGNet 差的 0.7 mm 可能在哪

自由空间的噪声双方都逃不掉，所以差距只能来自接触步和误差累积。按证据强弱排：

假设依据证据怎么验证（便宜）
H1 一步内的接触事件5% 的步占 45% 误差；我们假设修正力在 0.1 s 内不变，Act-FIGNet 也是单步，但它的网络看到的是整张网格的面-面关系，对"快碰上"更敏感强把误差最大的 5% 的步按"接触数是否变化"分组；修正力改为每 25–50 ms 调用一次
H2 测量滤波论文说位姿和 F/T 为同步做过滤波；"用 F_{t+1} 解释运动和 F_t 一样好"；学习模型会自然复现滤波后的平滑动力学，物理仿真不会中在推演输出上叠一个辨识出的线性滤波器；或把 a_{t+1} 作为输入（开环推演里动作序列已知）
H3 误差累积DAgger 一轮 −14%，说明累积是主要杠杆；但第二轮饱和强多步展开的线性化损失（串接 2–3 步），不改变在线数据分布
H5 基础求解器的接触分辨率子步 5 ms、软接触；求解器可能低估刚性接触的瞬态中子步改 2 ms 重跑基础评测，看 100 步误差是否下降
PART 3

修改方向：从目标和误差来源推导

3.1 设计原则

项目要的是什么

更快、更少标定、跨几何泛化。精度只是在这个 benchmark 上证明"混合路线不输"的手段，不是目的。LEGO Technic 装配需要的是"给 CAD 就能预测接触力和运动"。

不能动的

仿真器负责的部分（不穿透、导纳动力学、自由空间）不学；每个修正必须落在真实接触处并受物理约束。全局残差的发散已经证明：放宽这一条就会和约束打架。

该学的

只学仿真器算错的、而且数据里有信号的部分：接触步的力，尤其是接触事件附近。改动前先用诊断确认目标误差项存在且可学。

停止的

不再换表示来碰运气；不再调几何标定；不再加 DAgger 轮数。

3.2 三条主线

A · 精度

针对 2.4 右侧那块：接触事件 + 累积（H1、H3）

修正力改为一步内多次调用（每 25–50 ms），特征计算便宜；训练损失改为多步展开的线性化（2–3 步）。都不改变模型结构，只改"何时施加、如何监督"。

先做的验证
把误差最大的 5% 的步按"接触数是否变化"分组，确认长尾确实来自接触事件；半天
判据
见过的工具位置误差从 3.55 mm 降到 3.2 以下，且 OOD 不变差
成本
预计算改一次（30 分钟）、训练 10 分钟
B · 少标定

证明 LCR 能吸收基础仿真的参数误差

在只有自由空间质量阻尼、接触参数取默认值的基础仿真上训练 LCR，与"辨识过的基础 + LCR"比较。如果差距小，就能主张"网络替代了大部分标定"，这是相对纯学习方法的实质优势（它们用 40 万步数据换标定，我们用 2 万步辨识 + 训练）。

判据
未辨识基础上的 LCR 位置误差 ≤ 辨识基础上 LCR 的 1.1 倍
成本
一次完整流程，约 45 分钟；不改代码
延伸
网络输出"接触参数"（有效间隙、摩擦、刚度）而不是力的变体：可解释性最高，标定完全由网络承担
C · 泛化

把几何种类从 3 种扩到几十种

"局部几何特征带来泛化"目前只有一个方形工具的证据。LEGO Technic 零件（pin、axle、beam 孔，不同长度和摩擦版本）是最自然的扩展，也是项目本体。先在仿真里用 LDraw 几何批量生成，再采少量真实 F/T 校准。

判据
按零件类别留出测试集，LCR 的误差随训练零件数增加而下降，去掉几何特征的版本不下降
成本
数据采集为主；模型不用改

3.3 建议顺序

  1. 本周：A 的诊断（长尾归因，半天）+ B（45 分钟，不改代码）。两个结果都直接改变论文的主张。
  2. 下周：按诊断结果实施 A 的一步内多次调用和多步损失。
  3. 之后：C，并把可解释性实验补上（画出学到的接触力分布，对照摩擦锥）。

与 Act-FIGNet 的定位：不追求在它的 benchmark 上超过它，而是在精度接近的前提下，证明快 3 倍以上、只用 CPU、可解释、并且（待验证）少标定、跨几何泛化。这是一篇"物理结构化混合模型"的论文，不是一篇"新的图网络"的论文。
