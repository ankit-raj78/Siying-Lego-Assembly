A hybrid contact-dynamics model for Technic insertion

A dynamics model for LEGO Technic pin / axle insertion: given part CAD and a command, predict motion and contact force for downstream control. The proposal is to keep a rigid-body simulator in the loop and let a small network correct it only where contact happens.

FastRuns inside an MPC loop on CPU.
Little calibrationNew parts should not need new data.
Generalizes across geometryWorks on parts it has not seen.
01

Research question

Can a hybrid neural dynamics model match the accuracy of fully learned simulators for contact-rich insertion, while predicting faster and needing far less calibration data?
  • Accuracy — does correcting a simulator at its contact points beat learning contact from scratch?
  • Speed and data — how much of that accuracy survives with a small network trained on a fraction of the data?
  • Generalization — does the model transfer to part geometries it has not seen?

Design space

Every contact-dynamics model answers the same six questions. Each row is one question, from all-physics on the left to all-learned on the right. Existing methods are combinations of one choice per row; we will explore combinations along these axes and report which ones move accuracy, speed and generalization.

04

Next steps

  • Dataset and reference architecture: use an existing real-world insertion dataset with force/torque readings and a published learned-simulator baseline; reproduce that baseline and the plain-simulator baseline on it.
  • Preliminary hybrid: build a small contact-correction network on top of the simulator and compare it with both baselines on accuracy, speed and unseen geometry.
  • Then: vary the six axes against each other, and move to Technic parts (simulated part library + a small set of real F/T runs).
